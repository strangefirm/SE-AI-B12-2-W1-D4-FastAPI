This project is a simple web calculator. 
FastAPI is a Python framework for building APIs.
Here, /add, /subtract, /multiply, and /divide accept two numbers and return results as JSON.
The / route serves the calculator page, which calls those endpoints and displays the answer.
Visit /docs to test the API interactively.
FastAPI is a modern Python framework used to build APIs quickly and efficiently.
1. High Performance: Handles requests quickly and efficiently.
2. Easy to Learn: Simple Python syntax and beginner-friendly.
3. Automatic Documentation: Generates interactive API documentation using Swagger UI.
4. Data Validation: Automatically validates input data using Pydantic.
5. Asynchronous Support: Supports async and await for handling multiple requests.
6. Type Hints: Uses Python type hints to reduce errors.
7. Easy Integration: Works with AI models, databases, and web applications.
8. Time-Saving: Reduces development time with built-in features.
In short: FastAPI helps developers build fast, reliable, and well-documented APIs with Python
